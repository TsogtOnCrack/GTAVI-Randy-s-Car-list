# Randy’s 20 Cars

A standalone checklist for Randy’s 20 cars. Open [the site](./index.html) to use it. Checklist progress and replacement photos are saved in the current browser.

## Publish with GitHub Pages

1. Push this repository to GitHub on the `main` branch.
2. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**.
3. Open the **Actions** tab and wait for **Deploy to GitHub Pages** to complete. The deployment run shows the published site URL.

Future pushes to `main` publish automatically. You can also start a deployment manually from the workflow’s **Run workflow** button.
